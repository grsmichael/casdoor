链接主机默认取自本页地址栏（location.hostname）——本机用 localhost 打开最省事； 上方可一键切换为内网 IP，便于把链接分享给手机/同事。
关于「局域网 IP」为什么要靠脚本托管：Chrome/Edge 76+ 起浏览器默认隐藏本机内网 IP （WebRTC 的 host 候选被替换成 mDNS 随机名、srflx 的 raddr 被置为 0.0.0.0）， 纯前端无法探测。请用 python tools/nav/serve_nav.py 托管本页，页面即可同源读取准确的 内网 IP；自动探测失败时按提示手填一次即会记住。
健康状态由本导航服务在服务端探测（无跨域问题）：绿=在线、红=不可达、灰=探测中/未知。 鼠标悬停状态点可看 HTTP 状态码与 docker 容器状态。RADIUS 是 UDP 服务，脚本不做探测，恒为灰。
服务清单与默认账号都来自 tools/nav/services.json——加服务/改端口/改账号只改那一个文件， 探测、卡片、上方账号面板会自动同步。

首次上手路线

    起数据库：docker compose up -d db（等价 make deps）；起后端：go run main.go；起前端：cd web && yarn && yarn dev。
    整体容器化（后端会自己 build 镜像）：docker compose up -d；停止：docker compose down。
    默认账号见页面顶部「默认账号」面板（管理员 admin / 123；MySQL root / 123456，库名 casdoor）。
    本导航仅本地开发用（默认 8899，被占用时自动顺延，Ctrl+C 停止）。
    web-old 与 web 的 dev 脚本默认端口都是 7001，会撞车——对照旧前端时请用 PORT=7002 yarn start。
